# Maintainership

This is `@maxwbh/pdf-lib`, an extended fork of the original [pdf-lib](https://github.com/Hopding/pdf-lib) created by Andrew Dillon ([@Hopding](https://github.com/Hopding)).

## About This Fork

This fork extends the original `pdf-lib` with additional enterprise features:

- **PDF Encryption/Decryption** - Password protect documents
- **Incremental Save** - Preserve digital signatures when modifying
- **Hyperlinks** - Add clickable links to PDFs
- **Granular Permissions** - Control printing, copying, modifying, etc.

## Communication
